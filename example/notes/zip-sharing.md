# Zip sharing

A project can be exported as a .zip and imported again.

Export packs the canvases, notes and media, with unsaved edits included. Import reads a .zip, leaves out hidden files and anything unsafe, and opens the result as a project. If the archive has a single top folder, it is unwrapped. No account or server is needed, so this is also how a map moves between the browser and a folder. See [[start-here]] and [[cli]].
