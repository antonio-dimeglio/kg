# Start here

This is a map of kg itself, made with kg. Every card on the canvas is either a note, a text card, a link or another map.

Click a note card to read it on the right. Notes link to each other with `[[name]]`, and the Links tab lists what points where. A card with a map icon is a sub-map: click it to open that canvas, and use the breadcrumb at the top to go back up. Try [[graph]] first, then open the Page map from the overview.

The top bar has a Projects button. It leads to the start screen, where you can use Import .zip to open a project of your own, or New project to start an empty one in the browser. A project made in the browser lives in memory, so export it as a .zip before you leave; see [[zip-sharing]].

This copy is read only, so it cannot be changed. The View and Edit switch and the Save button appear when a project is opened with [[cli]] serve.
