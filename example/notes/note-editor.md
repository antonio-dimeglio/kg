# Note editor

The note panel edits a note in place, as rendered text.

Typing `# `, `- `, backticks or `[[` turns into formatting, and the markup shows again on the line with the cursor. The panel has three tabs: Note, Links and JSON. Focus hides the graph so the note fills the page.

Notes can hold maths with KaTeX, code with highlighting, Mermaid diagrams, images, video and audio. Pasting or dropping an image saves it under `assets/` next to the note. Changes are kept until saved; see [[save-flow]]. On a read only site the note is only shown. Colours come from [[palettes]].
